  🚀 NEXT STEPS (IN ORDER)
═══════════════════════════════════════════════════════════════

1. CREATE VIRTUAL ENVIRONMENT
   ─────────────────────────────────────────────────────────
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

2. INSTALL DEPENDENCIES
   ─────────────────────────────────────────────────────────
   pip install -e .

   Expected: ~30 seconds, all packages install successfully

3. RUN TESTS
   ─────────────────────────────────────────────────────────
   pytest

   Expected: All tests pass (may show warnings, ignore them)

4. VERIFY MODEL REPOS (MANUAL)
   ─────────────────────────────────────────────────────────
   Open these URLs in browser and check they exist:

   https://huggingface.co/bartowski/phi-4-GGUF
   https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF
   https://huggingface.co/Qwen/Qwen2.5-Coder-3B-Instruct-GGUF
   https://huggingface.co/bartowski/gemma-2-2b-it-GGUF
   https://huggingface.co/bartowski/Llama-3.2-3B-Instruct-GGUF

   If any fail: edit src/duomind/models.json and replace

5. GET JEV API KEY
   ─────────────────────────────────────────────────────────
   1. Visit: https://console.typesafe.ai
   2. Sign up / log in
   3. Create API key
   4. Save it (you'll enter it in step 6)

6. RUN SETUP WIZARD
   ─────────────────────────────────────────────────────────
   duomind setup

   This will:
   - Check your GPU/RAM/disk
   - Test Jev connection with your key
   - Show 5 model options
   - Prompt for llama-server.exe (download manually for now)
   - Download your chosen model (~2GB)

7. DOWNLOAD llama-server.exe (MANUAL)
   ─────────────────────────────────────────────────────────
   1. Go to: https://github.com/ggerganov/llama.cpp/releases
   2. Download: llama-*-bin-win-cuda12-*.zip (for CUDA 12.x)
   3. Extract llama-server.exe
   4. Move to: %LOCALAPPDATA%\duomind\binaries\

   To find exact path:
   python -c "from duomind.utils import get_binaries_dir; print(get_binaries_dir())"

8. START SERVER (MANUAL FOR NOW)
   ─────────────────────────────────────────────────────────
   python -m uvicorn duomind.server:app --host 127.0.0.1 --port 8000

   Expected: Server starts, shows "Uvicorn running on http://127.0.0.1:8000"

9. TEST API REQUEST
   ─────────────────────────────────────────────────────────
   In another terminal:

   curl -X POST http://127.0.0.1:8000/v1/chat/completions ^
     -H "Content-Type: application/json" ^
     -d "{\"model\":\"test\",\"messages\":[{\"role\":\"user\",\"content\":\"What is 2+2?\"}]}"

   Expected: JSON response with generated text

10. CONNECT CLINE OR KILO CODE
    ─────────────────────────────────────────────────────────
    In your AI coding assistant settings:

    API Provider:  OpenAI Compatible
    Base URL:      http://127.0.0.1:8000/v1
    API Key:       (leave blank)
    Model:         (the ID from setup, e.g., "qwen2.5-3b-q4")

11. BUILD FIGURE (IF YOU HAVE MIKTEX)
    ─────────────────────────────────────────────────────────
    python scripts/build_figure.py

    Then commit:
    git add docs/images/architecture.png
    git commit -m "docs: add architecture figure"

═══════════════════════════════════════════════════════════════
  🎯 WHAT THIS ACHIEVES
═══════════════════════════════════════════════════════════════

DuoMind is a LOCAL AI server that:

✓ Runs small LLMs (2-4B) on your RTX 3060 6GB
✓ Uses Jev for ALL classification decisions
✓ Keeps generation PRIVATE (only classification goes to cloud)
✓ Works with Cline and Kilo Code (OpenAI-compatible API)
✓ Non-technical setup (9-step wizard with plain English)
✓ Toggle Jev ON/OFF for A/B comparison
✓ Switch models without re-setup
✓ Fallback when Jev fails (circuit breaker)
✓ Caches Jev responses (reduces cost)

The experiment: Can a small local model + Jev classification
beat a pure small model? Run benchmarks to find out.

═══════════════════════════════════════════════════════════════
  ⚡ WHAT TO EXPECT
═══════════════════════════════════════════════════════════════

Performance (estimates for RTX 3060 6GB with 3B model):
  First token:     1-3 seconds (cold start)
  Generation:      10-30 tokens/second
  Jev overhead:    70-500ms per request
  RAM usage:       4-6GB
  VRAM usage:      2-4GB

Cost (Jev only, LLM is free/local):
  Per request:     $0.0001 - $0.001 (varies by prompt size)
  Heavy use:       $1-5 per month (rough estimate)

Known limits:
  - Small models make mistakes (no magic)
  - Jev adds latency (batched, but still 70-500ms)
  - No proof this helps until you benchmark
  - Early access software (rough edges expected)
